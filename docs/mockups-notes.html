Other ways to move

  • Drag a note onto a folder in the tree (option C).
  • Pick a project: “Move into project…” also sets project: so it shows on the dashboard.
  • Many at once: tick several notes in the list, then Move.
  • Safe like everything else: refused if the file changed on disk, and it never overwrites a note that is already there.

The ⋯ menu is the only header action. A thin bar above the keyboard holds the typing helpers (checkbox, link, tag, person, undo). Long-press a note in the list for its menu. There are no keys, so the menu and the palette matter most.

My recommendation

A Jump back in as the landing, with Recent and Pinned. ⋯ menu plus right-click for actions, Ctrl+P palette, and Move to… built on the Rename pipeline with a preview. Option C (folder tree) as an optional toggle in the list for large folders. Tell me what to change, or say “build it”.
