Three zones. A project rail to switch projects without going back. A main area with tabs (Tasks, Board, Timeline, Notes). A status column that is always visible: progress, who has what, what is next.

2. Making hundreds of tasks manageable

Group by anything

One control chooses how the list is grouped: due bucket (the default), status, person, tag, phase or note it lives in. Groups collapse, show a count and a mini progress bar, and remember their state. Long groups show the first 25 and a "show 25 more", so the page stays fast on a phone.

Phases without new structure

A phase is just a heading in the project note (## Phase 1) for tasks written under it, or a phase: value on a task note. Nothing to set up first. The hub reads them and shows progress per phase, which is the project's real shape.

Filter chips and saved views

Type to filter inside the project, click a person, tag, status or date to add a chip. Save the combination as a named view ("My open tasks", "Waiting on") that appears in the rail for every project. A saved view is a small file in .plainfile/views/, so it syncs with the folder.

Act on many at once

Tick rows (or press x), and a bar appears: Set due…, Status…, Assign @…, Tag…, Move to project…, Done. Every change is previewed as the exact lines that will change, written with the same guarded writes, with one Undo.

Edit in place

Click a due chip for the date picker, the status chip to change it, a name to reassign. No need to open the note. Keys: j/k move, x select, d due, s status, Enter open.

Always-visible status column

The empty right side becomes the project's dashboard: progress, phases, who has what, what is next, and a small done-per-week chart. It stays while you scroll, so you never lose the overview.

Build order I would suggest

1 Tabs, group-by control, collapsing groups with counts, filter chips, and "show more" paging (fast with hundreds of tasks).
2 The always-visible status column (progress, phases from headings, who has what, next up) and the project rail.
3 Edit in place plus multi-select with bulk actions and Undo.
4 Board and Timeline tabs, saved views, and the portfolio table.
